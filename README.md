# Лазерный стол

Нативное приложение macOS для домашнего лазерного гравёра на **GRBL 1.1** (стол около **400×400 мм**).  
Интерфейс на русском: спокойные кремовые и терракотовые тона, компактные кнопки.

Станок **без защитной крышки** — в программе нет тумблера крышки и связанных блокировок.

## Что умеет v1

- Слои **Прожиг** (растр) и **Рез** (контур), несколько объектов на листе
- Новая бирка: прямоугольник / овал / свой размер
- Свободный контур (карандаш) + прямоугольник и овал
- Импорт **JPG / PNG** и простой **SVG** (`path`, `rect`, `circle`, `ellipse`, `polyline`, `polygon`)
- Цвет → ч/б с порогом, инверсия, отражение по горизонтали и вертикали, поворот, масштаб, перенос
- Прозрачность PNG не прожигается
- Размножение сеткой с зазором
- Пресеты материалов (фанера, картон, бумага, кожа, оргстекло)
- Оценка времени, превью рамки (лазер выключен)
- Старт слоя прожига, слоя реза или всего листа
- Пауза и стоп
- **MockGRBL** для демо без железа и реальный последовательный порт (IOKit + POSIX, 115200 8N1)
- G-code: растр (двунаправленные пробеги) и контур
- Автосохранение последнего проекта
- Заготовка библиотеки монограмм

## Требования

- macOS **12.0** и новее (проверено по целевой платформе; у автора — 12.7.6)
- Xcode **14.2** (Swift 5.7, без API macOS 13+)
- Опционально: USB-UART к плате GRBL 1.1 в лазерном режиме (`$32=1`)

## Как открыть и запустить

1. Откройте `LaserStol/LaserStol.xcodeproj` в Xcode 14.2.
2. Схема **LaserStol**, целевая ОС macOS 12.
3. Signing: локально достаточно ad-hoc (`CODE_SIGN_IDENTITY = "-"`). Подставьте свою команду, если нужно.
4. ⌘R. При первом запуске подключается **макет GRBL**, на столе — демонстрационная сетка букв 400×400 мм.

Демо без станка:

1. Кнопка связи → канал «Макет (Mock GRBL)» → Подключить (уже по умолчанию).
2. **Превью** — обводка рамки, лазер выключен.
3. **Старт всего листа** → проверка → **Начать**. Ползунок прогресса, **Пауза** / **Стоп**.

Железо:

1. Обновите список портов (`/dev/cu.*`).
2. Выберите порт, 115200 8N1.
3. Убедитесь, что GRBL в лазерном режиме. Приложение не делает `$H` принудительно: вы подтверждаете, что голова на месте.

## Интерфейс

| Экран | Где в приложении |
| --- | --- |
| Рабочий стол | Главное окно: инструменты слева, холст, слои справа, действия снизу |
| Новая бирка | «Фигуры» |
| Превью / проверка | «Превью», «Выжечь слой», «Вырезать слой», «Старт всего листа» — без крышки |
| Идёт работа | После «Начать»: прогресс, пауза, стоп |
| Слои и сетка | Панель «Слои», «Размножить сеткой» |

Инструменты: **Открыть** (растр/SVG), **Текст**, **Фигуры**, **Монограмма**, **Контур**.  
На холсте: перетаскивание, угловые маркеры масштаба, маркер поворота.

## Архитектура

```
LaserStol/
  App/            SwiftUI @main, AppState
  Models/         проект, слои, объекты, пресеты, монограммы
  Services/
    GCode/        растр, контур, оценка времени, сборка задания
    Machine/      GRBLController, MockGRBLTransport, SerialPortTransport
    ImageProcessor, SVGImporter, ProjectStore
  UI/             тема, рабочий стол, холст AppKit, мастера, задание
```

- **Координаты документа** — миллиметры, начало в левом нижнем углу, Y вверх (как у GRBL).
- **Прожиг** — серый буфер, порог, прозрачные пиксели пропускаются, `M4` + горизонтальные пробеги.
- **Рез** — ломаная / скруглённый прямоугольник / овал / отверстие бирки.
- **MockGRBLTransport** отвечает `ok`, считает строки, умеет `!` / `~` / `0x18`.
- **SerialPortTransport** — IOKit enumeration + `termios`. ORSSerialPort не подключён, чтобы проект открывался в Xcode 14.2 без SPM.
- Последний проект: `~/Library/Application Support/LaserStol/LastProject.json`.

Тесты: схема **LaserStol** → ⌘U (геометрия сетки, порог, G-code, SVG, документ).

## Безопасность

Это управление лазером. Следите за материалом, вытяжкой и тем, что луч не выходит за заготовку. Приложение не заменяет здравый смысл и не моделирует крышку — её у станка нет.
